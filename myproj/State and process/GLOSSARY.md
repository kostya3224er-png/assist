# Глоссарий

| Термин | Простое значение |
|---|---|
| Project в ChatGPT | Рабочее пространство с общими инструкциями, файлами и несколькими отдельными чатами. |
| Контекст Project | Загруженные постоянные документы и инструкции; это не автоматическая синхронизация с папкой Windows. |
| Codex | Инструмент, который может работать с локальной папкой проекта и менять файлы, если ему доступна эта папка. |
| Источник | Документ или текст, добавленный в базу знаний Assist. |
| Тема | Группа источников, которую пользователь может включить или выключить. |
| Retrieval | Локальный отбор фрагментов источников для передачи модели. |
| Prompt | Инструкции модели: роль, ограничения, пожелания и формат ответа. |
| Архив правил | Старые/исторические записи внутри пользовательской базы; не путать с ZIP-архивом файлов проекта. |
| `assist-data.json` | Локальный профиль приложения; может содержать настройки, источники и историю, поэтому его нельзя без проверки публиковать. |
| `istok.json` | Экспорт только базы знаний в JSON в проверенном наборе; в карте хранятся лишь названия/размеры, не тексты. |
| `[F#]` | Ссылка модели на переданный фрагмент источника; должна соответствовать контексту конкретного запроса. |
| KB map | Карта тем/источников с метаданными; не копия полного содержимого источников. |
