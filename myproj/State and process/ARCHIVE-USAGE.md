# Как использовать архив проекта

Здесь есть короткий ZIP для передачи контекста ChatGPT/Claude и полный технический ZIP для Codex. Это не архив правил внутри базы Assist и не резервная копия приложения.

## Для чего он нужен

- Перенести комплект документов одним файлом.
- Хранить снимок документации на определённый момент.
- Быстро распаковать структуру на другом компьютере.

## Как пользоваться

1. Для ChatGPT/Claude обычно добавляй основные `.md` файлы по отдельности — их проще обновлять и заменять.
2. Для короткой передачи приложи `Assist-Shared-Context.zip`; полный `Assist-Codex-Reference.zip` содержит дополнительные заметки и шаблоны.
3. Не распаковывай поверх папки приложения: внутри только документация и инструкции.
4. При обновлении документов пересоздай архив; ZIP не обновляет уже загруженные файлы в ChatGPT Project автоматически.
5. Перед отправкой проверь состав архива. Здесь не должно быть API-ключей, полной истории чатов, `assist-data.json`, исходных материалов, `node_modules` или exe.

Архив — переносной снимок, а не единственный оригинал. Редактируй Markdown в рабочей папке `myproj`, затем пересобирай ZIP.
