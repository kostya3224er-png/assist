# Шаблон задачи для Codex

```text
Цель: [какой наблюдаемый результат нужен]

Симптом/пример:
[точный вопрос, ошибка, скриншот или шаги воспроизведения]

Область:
[функция/файлы, если известны]

Ограничения:
- Не менять: [например, поиск сверху / профиль источников / UI]
- Не запускать: [если есть ограничение]
- Сохранить: данные пользователя, фокус игры, универсальность проекта

Готово, когда:
[критерии приёмки, включая ожидаемое поведение]

Проверка:
[статическая проверка / тест-кейсы / сборка — только нужное]
```

Для ошибки добавляй фактический лог и минимальные шаги. Удаляй из логов ключи, токены и личные данные. Не описывай желаемую реализацию слишком рано: сначала попроси определить причину, затем исправить её.
