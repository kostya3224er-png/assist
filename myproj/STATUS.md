**Сверка кода:** 11.10.2026. Основание: рабочая папка `C:\Users\Admin\Desktop\project`, исходники и конфигурация. В этой сессии исправлены подтверждённые ошибки из аудита; exe не собирался, приложение не запускалось.

## Подтверждено в текущем коде

- Assist — Windows/Electron overlay с чатом, темами и источниками, настройками, историей, FAQ, горячими клавишами и голосовым вводом.
- Верхний поиск по источникам отделён от генерации AI-ответа.
- Для AI из включённых тем локально отбираются фрагменты, формируется контекст и отправляется запрос к подключённому провайдеру.
- В проекте есть OpenAI Chat Completions/Responses и Gemini пути; OpenAI-compatible поддерживает потоковый вывод.
- Полное время последнего ответа отображается в поле `latLabel`.
- Короткий жёсткий лимит в 8–10 секунд в актуальном `main.js` не подтверждён. Завершение может зависеть от провайдера, сети, ошибки или ручной отмены.
- Есть сетевые/HTTP повторы и совместимые повторы при некоторых параметрах. Поэтому ровно один сетевой вызов не гарантирован.
- Тестовые файлы и фикстуры находятся в `tests/`; наличие тестов не означает, что результаты актуальны для пользовательской базы.
- Устаревший `searchDictionary` удалён из рабочего поиска; старое поле мигрируется из сохранённых тем. Остались только общие синонимические группы; игровые алиасы убраны, короткие совпадения по префиксу ограничены.
- AI-контекст для модели ограничен 9 фрагментами и 15 000 символами; поиск кандидатов по-прежнему проходит по всем включённым источникам.
- Потоковые дельты уже отображаются в чате; пункт о «снятии блокировки стриминга» из рекомендаций не требовал правки.
- Yandex SpeechKit повторяет один раз запрос на HTTP 500/502/503/504 с паузой 700 мс; ошибки авторизации и квоты не повторяются.
- `reasoning_effort: low` добавляется лишь для распознанных reasoning-моделей на совместимых путях; `temperature` для них не передаётся. Лимит ответа — 700 токенов в кратком режиме и 1800 в полном; индикатор сообщает о замеченном обрезании.
- Сохранение профиля переведено на последовательную асинхронную очередь; ручное добавление и изменение источников ограничено суммарными 45 МБ. Эталоны ответа хранятся отдельно от истории, поэтому очистка истории их не удаляет.
- Подтверждённые исправления: русский follow-up больше не зависит от `\b`; частичный ответ с `[DATA_INSUFFICIENT]` сохраняет найденную часть; ссылки и offline-сообщение не приписывают ответ непереданным фрагментам; проверки аудио нельзя запускать одновременно с распознаванием; речь распознаётся без предварительного отсева не-вопросов.
- HTTP разрешён только для локальных endpoint; при недоступном Windows `safeStorage` интерфейс предупреждает о незашифрованном хранении ключей. Win-модификатор распознаётся, а глобальный клик-бинд учитывает режим пропуска мыши.
- Системный аудиопоток `loopback-capture` сверён по установленной версии 3.0.2: 16-bit PCM, 2 канала, 48 kHz; это совпадает с декодером renderer.
